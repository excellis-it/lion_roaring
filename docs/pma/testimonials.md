# Testimonials

## What this is

**Testimonials** is the CMS for quotes/stories shown on the **public website**. Staff create and edit entries here; visitors only see the published public page.

---

## Who can use it

| Action | Permission |
|--------|------------|
| Open Testimonials | **Manage Testimonials** |
| Create | **Create Testimonials** |
| Edit / Delete | Edit / Delete Testimonials |

---

## Country / content rules (read carefully)

Website CMS content is **per country code**:

- **Global** editors (or Super Admin on the global domain) often get a **Content Country** choice. Default is usually **US**.
- **Regional** editors are locked to **their own** country.
- If a country has **no row yet**, the editor may **prefill from US** as a starting draft. Saving creates a **new** row for that country — it does **not** overwrite the US original.

This US-prefill pattern matches other CMS areas (see **Pages (CMS)**).
