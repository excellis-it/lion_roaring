# Messaging

## What this is

**Messaging** groups three ways people communicate inside the PMA:

1. **Chats** — one-to-one conversations  
2. **Team** — group / team spaces  
3. **Mail** — internal mail compose and inbox-style tools  

The parent menu appears if you have **any** of: **Manage Chat**, **Manage Team**, **Manage Email**. Each child still needs its own permission.

---

## Chats

### Purpose

Private messages between eligible panel users.

### Who can open Chats

Permission: **Manage Chat**.

### Rules that confuse people

| Topic | Rule |
|-------|------|
| Who you can message | Active users with eligible role types (staff/member classes used by the product) |
| Super Admin address book | Broader — can reach eligible users more widely |
| Non–Super Admin address book | Narrower visibility helpers; you may only see a Super Admin in the list after they messaged you first |
| Delete | Often “delete for me,” not erase for the other person |
| Names | Display names are protected from auto-translate |

### Attachments (plain summary)

- Images: common formats including JPEG, PNG, GIF, WebP, HEIC/HEIF, JFIF. HEIC is converted when possible; otherwise offered as download.
- Videos: common formats play in an in-app player when the browser supports them; otherwise download is offered with a clear message.
- Tall images open in a lightbox sized to show the full picture.

---

## Team

### Purpose

Shared team chat spaces (create/join/manage depending on permissions).

### Who can open Team

Permission: **Manage Team**. Extra permissions such as **Create Team** / **Delete Team** may exist on roles for those actions.

### Rules

- Same attachment behavior as Chats.
- Adding someone to a team does **not** create a new account — they must already exist (see **Create Member** / **All Members**).
- Group avatars fall back to a default image if a custom file is missing.

---

## Mail

### Purpose

Send and manage internal mail to active users.

### Who can open Mail

Permission: **Manage Email**.

### Rules

- Recipients are active users.
- Star, trash, and restore behaviors follow the mail UI (items can sit in trash until restored).
