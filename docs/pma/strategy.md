# Strategy

## What this is

**Strategy** is an internal document library for strategy files. Staff upload documents so the right people can find, open, download, or remove them later.

It is **not** a public marketing page. Public strategy-style content on the website (if any) would be edited under **Pages (CMS)** or related CMS menus instead.

---

## Who can use it

| Need | Permission |
|------|------------|
| Open Strategy | **Manage Strategy** |
| Upload | **Upload Strategy** (when granted on the role) |
| View / Download | View / Download Strategy |
| Delete | **Delete Strategy** |

If you can open the menu but cannot upload, your role is missing the upload permission.

---

## Country scoping — why two people see different files

Every file is stored with a **country** scope. The library you see depends on User Type and which website host you are on:

| Situation | Library you work in |
|-----------|---------------------|
| Super Admin | Can work across countries; can choose scope when uploading |
| Global user on the Global site | **GL** (global) library |
| G_R user on the Global site | Usually treated like Global → **GL** |
| Regional user on their country site | **That country only** |
| G_R user on their regional site | **That country** |
| Ecclesia-limited user | May see only houses they manage |

### Practical examples

- A Regional staff member in Country A will not see Country B’s strategy files.  
- A Global staff member looking for a regional file may need to be on the right host / scope — or ask a Super Admin.  
- “I uploaded it yesterday and my colleague cannot see it” almost always means different country scope or different host, not a broken upload.

---

## Typical actions

1. Open Strategy from the sidebar.  
2. Browse files available in your scope.  
3. Upload (if permitted), choosing or inheriting the correct country.  
4. View or download.  
5. Delete only when you have Delete Strategy (and product rules allow it).

Deleted items may be recoverable by Super Admin under **Restore** when soft delete applies.
